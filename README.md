# 📹 Kinescope Video Extractor

Скрипт для извлечения ссылки на видео из Kinescope и генерации команды `ffmpeg` для его загрузки.

## 📝 Описание

Этот скрипт предназначен для использования в браузере на страницах с встроенными плеерами [kinescope.io](https://kinescope.io). Он автоматически:

* Ищет JSON-LD разметку с данными о видео
* Извлекает ссылку на потоковое видео (`.m3u8`)
* Генерирует `ffmpeg` команду для загрузки видеофайла

Полезен для архивирования видео из закрытых LMS или других платформ, использующих Kinescope.

## ⚙️ Как использовать

1. Откройте страницу с видео Kinescope в браузере (где видео встроено через `<iframe>`).
2. Откройте консоль разработчика (обычно `F12` → вкладка **Console**).
3. Вставьте весь скрипт и нажмите Enter.
4. В консоли появится готовая команда `ffmpeg`, которую можно скопировать и использовать в терминале.

Пример:

```bash
ffmpeg -headers "Referer: https://kinescope.io/" -user_agent "Mozilla/5.0" -i "https://cdn.kinescope.io/abc123/master.m3u8" -c copy -bsf:a aac_adtstoasc "Название видео.mp4"
```

## 📦 Требования

* Установленный [`ffmpeg`](https://ffmpeg.org/)
* Современный браузер с поддержкой JavaScript

## ⚠️ Предупреждение

Этот скрипт **не обходит DRM или платные ограничения**. Он предназначен только для работы с видео, доступным в открытом виде или через обычные LMS.

Перед использованием убедитесь, что вы не нарушаете авторские права и условия использования сайта.

## 🛠 Структура скрипта

* `extractVideoDataFromDocument(doc)` — извлекает JSON-LD с данными видео
* `fetchIframeContent()` — загружает содержимое iframe, если видео внутри него
* `generateFFmpegCommand()` — логика получения `contentUrl` и генерации команды
